# Week 2 Exploration — Strategy and metric semantics

Short, balanced, and broad character windows were selected to isolate chunk-size/context trade-offs while holding the boundary algorithm and embedding adapter constant. Precision@K, Recall@K, Hit Rate, and MRR were retained because each answers a different retrieval question. No aggregate “quality score” was created.

An observed strategy leader is local to the controlled corpus and test set. Statistical significance, external validity, and ANN latency claims remain out of scope.
