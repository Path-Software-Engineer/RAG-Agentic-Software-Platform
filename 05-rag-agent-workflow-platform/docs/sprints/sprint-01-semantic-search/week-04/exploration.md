# Week 4 Exploration — Product flow

Routes: `/documents`, `/search`, and `/citations/[citationId]`. The user begins with ingestion, moves to retrieval, and can resolve each result into durable evidence.

Required states: loading, empty, success, validation error, service unavailable, no results, and missing citation. The interface uses semantic HTML, explicit labels, visible keyboard focus, status text in addition to color, 44-pixel interaction targets, and reduced-motion behavior.

Release criteria: complete E2E flow, valid contracts, empty-database migration, responsive evidence, documentation, and an honest evidence boundary.
